# ИЛЮХА.EXE — Патч 32.0

Персональная ретро-RPG-открытка: восемь глав, пиксельный арт из `assets/`, живой чиптюн и финальный трек «Старый сейв». Не лендинг и не набор карточек — это маленькая игра, которую проходят кликами и читают.

**Стек:** Vite 8 · React 19 · TypeScript 5.9 (strict) · CSS без фреймворков · Web Audio API.
Без роутера: один редьюсер, восемь экранов, сохранение в `localStorage`.

---

## Быстрый старт

```powershell
npm install
npm run dev        # http://localhost:5173
npm run build      # tsc --noEmit && vite build
npm run preview    # http://localhost:4173 — проверка собранной версии
npm run verify     # Playwright: весь сценарий в реальном Chromium + скриншоты
```

Требуется Node.js ≥ 22.6 (скрипты сборки ассетов и аудио запускают `.ts` напрямую).

## Восемь глав

| # | Глава | Что происходит | Иллюстрация |
|---|-------|----------------|-------------|
| 01 | Запуск | CRT-экран грузит «сохранение Детство», кнопка PRESS START | `night-room-retro` |

| 03 | Два стула, одна парта | три варианта школьного поведения, у каждого своя реакция | `classroom` |
| 04 | Ещё пять минут | мини-игра: ровно шесть нажатий, шесть реплик, 23:40 → 05:10 | `night-room-cozy` |
| 05 | Новая игра+ | Диана, Маргарита, младший; сложность выше награда лучше | `family-portrait` |

## Управление и доступность

- Мышь, тап, клавиатура: `Tab` / `Enter` / `Space`. У всех кнопок видимый `:focus-visible`.
- Настройки (шестерёнка в HUD): музыка вкл/выкл, эффекты вкл/выкл, две отдельные громкости, список всех 13 достижений, сброс прогресса.
- `prefers-reduced-motion` отключает анимации и «бегущую строку» на арте.
- Контраст текста проверяется автоматически (WCAG AA) на всех восьми экранах.
- Мобильная вёрстка от 320 px: HUD перестраивается в две строки, карта глав скроллится, кнопки на всю ширину.

## Аудио

**Фоновая музыка** — не файл, а живой чиптюн на Web Audio API (`src/audio/`):

- 100 BPM, 12 тактов, **28.8 с**, бесшовный луп; мелодия + бас + арпеджио + барабаны;
- пульсовые волны 12.5 / 25 / 50 % собираются через `PeriodicWave` (никаких сэмплов);
- планировщик с опережением 0.18 с, один `AudioContext` на страницу;
- запускается только после жеста (PRESS START или первый клик/клавиша), играет непрерывно между главами;
- отдельные шины музыки и эффектов, плюс отдельная громкость каждой;
- на финале чиптюн приглушается (duck), когда играет подаренный трек.

**Финальный трек «Старый сейв».** В комплекте лежит сгенерированная демо-версия `public/audio/old-save-demo.wav` (31 с, та же композиция, отрендерена в WAV скриптом `npm run audio`). Плеер в финале умеет: выбрать файл, play/pause, перемотку, текущее время и длительность, имя файла, понятные ошибки, замену трека.

Чтобы поставить настоящий экспорт из Suno:

1. положите файл в `public/audio/old-save.mp3` (подойдут также `.m4a`, `.ogg`);
2. пересоберите — плеер сам предпочтёт его демо-версии (порядок: `old-save.mp3` → `.m4a` → `.ogg` → `old-save-demo.wav`);
3. либо просто выберите файл кнопкой в плеере — он играет локально, у других слушателей его не будет.

## Тексты без пересборки (скрытый редактор)

Любую фразу в игре можно поменять, не трогая код. Редактор не виден гостю, вход — по одному из секретов:

- открыть сайт с `?admin` или `#admin` (например, `http://localhost:5173/?admin`);
- нажать `Ctrl+Alt+A`;
- пять раз быстро кликнуть по логотипу `ИЛЮХА.EXE` в шапке (годится для телефона).

В панели: поиск, поля на текущем экране, кнопка «вернуть» у каждой правки, экспорт/импорт `texts.json` и JSON-режим для ручных пар «было → стало». Правки применяются к странице сразу и лежат в `localStorage` (`ilyuha-texts-v1`) того браузера, где их сделали.

Как отдать правки Илюхе: «Экспорт texts.json» → положить файл в `public/texts.json` (в репозитории уже лежит пустой `{}`) → `npm run build`. Можно и без пересборки: положить `texts.json` рядом с `index.html` на хостинге — он подхватится при загрузке. Порядок приоритетов: авторский текст → `public/texts.json` → правки из `localStorage`.

Хитрость реализации: ключ правки — сам исходный текст (пробелы нормализуются), поэтому React-перерисовки и переходы между главами не теряют замену, а удаление правки возвращает исходную строку. Смоук-тест редактора — `npm run texts` (12 проверок).

## Проверки

`npm run verify` собирает проект и прогоняет **112 автоматических проверок** в реальном Chromium: все восемь глав, все варианты выбора, шесть нажатий мини-игры, баф, плеер (play/pause/seek/duck), сохранение прогресса и громкости, отсутствие горизонтальной прокрутки и обрезанного текста на 390 и 320 px, контраст WCAG AA, `prefers-reduced-motion`, отсутствие растянутого сверх оригинала пиксель-арта и ошибок в консоли. Скриншоты складываются в `tools/screenshots/`, машинный отчёт — в `tools/verify-report.json`.

`npm run typo` — отдельный аудит типографики: считает «чернильные островки» в заголовке (слипаются ли буквы), проверяет, что кириллица берётся из своих сабсетов, что нет отрицательного `letter-spacing` и что заголовок не обрезается на 320–390 px. Скриншоты и отчёт — `tools/screenshots/typo-*.png`, `tools/typo-report.json`.

Отдельно `npm run devcheck` проходит сценарий в dev-режиме и падает, если React ругается предупреждениями (ключи, вложенность, контролируемые поля).

Ассеты пересобираются скриптами:

```powershell
python tools/prepare_media.py     # assets/*.png → public/media/*.webp + манифест
node tools/fetch-fonts.mjs        # WOFF2 + src/styles/fonts.css
node tools/render-audio.ts        # демо-трек в WAV
python tools/inspect-shots.py     # статистика скриншотов
```

## Что осталось за кадром

- **В `assets/` нет настоящих фотографий** — только семь сгенерированных пиксельных иллюстраций. Лица взяты из них как есть (только кадрирование), ничего не дорисовывалось и не «улучшалось». Сходство с реальными Илюхой, Дианой и Маргаритой по этим файлам подтвердить нельзя: AI-арт не гарантирует портретного соответствия. Как подставить реальные фото — в [docs/ASSETS.md](docs/ASSETS.md).
- Младший сын (~6 месяцев) в кадре не опознаётся отдельно: в иллюстрации семья втроём-вчетвером, и я не стал утверждать, кто именно там кто.
- Текста, «запечённого» в картинки, я не добавлял; но и OCR-проверку исходных PNG не делал — если в них есть надписи, они остались как есть.
- Музыка и звуки синтезированы, а не записаны с инструментов; демо-трек — это та же композиция, а не студийный мастеринг.
- Публикация в подкаталоге проверена: `npx vite build --base=/game/` корректно переписывает фавикон, шрифты, медиа и аудио — достаточно поменять `base` в `vite.config.ts`.
